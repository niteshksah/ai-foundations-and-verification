# Mission 1 — Build the AI and ML Landscape

## 1. Answer

Artificial Intelligence (AI) is the broad field of developing computer systems that perform tasks associated with intelligent behaviour. Machine Learning (ML) is a part of AI in which systems learn patterns from data instead of relying only on explicitly written rules.

Deep Learning is a type of ML that uses neural networks with multiple layers. Generative AI produces new content, such as text, images or code. Large Language Models (LLMs) are models designed to process and generate language; many modern LLMs use transformer architectures.

*Note: This is a simplified concept map. Generative AI is not limited to LLMs or to one particular model architecture.*

## 2. Five Important Distinctions

1. **AI vs. ML:** AI is the broader field, whereas ML is one approach used to develop AI systems.
2. **Rule-based programming vs. ML:** A rule-based program follows conditions written by a programmer. An ML model learns patterns from training data.
3. **ML vs. Deep Learning:** Deep Learning is a subset of ML that uses neural networks with multiple layers.
4. **Generative AI vs. predictive systems:** Generative AI creates content, while a predictive system estimates an outcome or category. Some systems can perform both kinds of tasks.
5. **LLM vs. AI agent:** An LLM processes and generates language. An AI agent can combine a model with tools, actions and a workflow to pursue a goal.

## 3. Three Examples

| Example | Classification | Reason |
|---|---|---|
| A fan switches on when temperature exceeds 30°C using a fixed condition. | Rule-based programming | The action follows an explicitly programmed threshold. |
| An ML model estimates chip power from historical design measurements. | Machine Learning | It learns relationships between input data and numerical outcomes. |
| An AI assistant generates Verilog code from a natural-language instruction. | Generative AI | It creates new code based on the user's prompt. |

The chip-power example is an illustrative proposed application, not a claim that a particular deployed system has been verified.
